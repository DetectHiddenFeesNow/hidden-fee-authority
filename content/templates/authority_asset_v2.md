# Authority Asset Template v3 — Research-Grade Authority Report

## REQUIREMENT: UNIQUE INDUSTRY-SPECIFIC HEADINGS

Do NOT copy the generic heading names below verbatim. Each report must use topic-specific section headings that match the industry.

**Examples of customization:**
- Instead of "Industry Analysis" use: "Medical Billing Fee Landscape" / "Bank Fee Structure Analysis" / "Home Service Pricing Practices" / "Insurance Pricing and Fee Practices" / "Subscription Fee Models"
- Instead of "Consumer Impact" use: "Financial Impact on Patients" / "How Project Costs Increase" / "Recurring Fee Impact on Households"
- Instead of "How Fees Are Hidden" use: "Dealer Fee Disclosure Tactics" / "Medical Billing Complexity" / "Telecom Surcharge Practices"
- Instead of "Methodology" use: "Research Approach" / "Data Analysis Method" / "Industry Fee Analysis Framework" / "Consumer Pricing Research Method"
- Instead of "Detection Methods" use: "Identifying Hidden Fees in Contracts" / "How to Spot Billing Errors"

**However**, the GENERATOR will still scan for key terms like "Real-World Example", "Fee Impact Table", "Hidden Fee Warning Signs", "Methodology", and "References" using prefix matching. Your customized heading must START with the required keyword. Examples:

✅ "Real-World Example: Medical Billing Case Study" — passes detection
✅ "Fee Impact Table: Auto Dealer Categories" — passes detection
✅ "Methodology: Industry Fee Research Approach" — passes detection
❌ "Case Study: Real-World Example" — FAILS detection (doesn't start with keyword)
